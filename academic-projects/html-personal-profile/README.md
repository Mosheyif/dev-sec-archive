# Personal Profile Page

Static HTML page with a personal bio, course list, hobbies, and a course
registration form with client-side validation.

---

## Structure

| Path | Purpose |
|---|---|
| `index.html` | Main profile page |
| `result.html` | Form submission result page |
| `css/styles.css` | Custom styles |
| `js/functions.js` | Form validation helpers |
| `images/` | Local image assets |
